## Two corrections that do not change the binary label

The legacy wig annotation described a doctor. The inspected transcript explicitly
attributes the action to a wig shop owner. The label remains rejected, but the
attribution correction matters: a mistaken professional role can falsely lend
authority to an anecdote. Original wording is retained as history; the current
contextual reason records the correction.

The quantitative computing example contains both “less than 15%” and “10%” for
the later CPU share. They are not silently reconciled. The claim-to-comparison
structure is present, but that is not a numerical fact-check. Similarly, a named
example in a contentious speech does not establish the truth of the allegation.

## Practice implication and boundaries

A useful drafting exercise is to identify the broad point, choose a suitable
kind of illustration, state how it relates to the point, and distinguish an
observed case from a hypothetical one. Then ask whether the case merely clarifies
the claim or is supposed to substantiate it. That practice hypothesis follows
the observed rhetorical distinctions; this project has not measured whether it
improves understanding or persuasion.

The practice card now names the mixed subtypes and warns against treating
illustration as verification. No acoustic or visual behavior was inferred from
these text judgments. Larger inspected contexts change the disjoint reference
pool, so that comparison was rebuilt even though binary support stayed constant.
