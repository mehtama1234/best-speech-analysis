# Draft lesson: mark the takeaway

Status: draft practice hypothesis; not learner-validated.

## Communication job

Help the listener recognize what the preceding explanation adds up to, while
preserving the qualification or evidence needed to interpret it correctly.

## Practice task

Explain a small topic in three or four sentences. Then make the close explicit:

1. State the takeaway in one sentence.
2. Name the evidence or reasoning that supports it.
3. State the most important limit or exception.
4. Give the listener one action, question or recall prompt.

Template:

> “The takeaway is **[claim]**. That follows from **[evidence/reasoning]**.
> It does not establish **[limit]**. Before we move on, remember or do
> **[next step]**.”

## Self-check

- Did I clearly mark the takeaway?
- Does it actually follow from the explanation?
- Did I preserve the essential qualification rather than compress it away?
- Could a listener restate the takeaway without my notes?
- Did I avoid using “in short” or “the point is” as a substitute for reasoning?
- Is a visual recap, written summary or question better for this audience?

## When not to use it

Do not summarize before the listener has the necessary context, and do not make
a complicated issue sound settled merely because the ending is memorable. If
there are several valid conclusions, name the choices rather than forcing one.
Use captions, headings, a written recap or extra processing time when auditory
signposting alone would be inaccessible.

## Learner check

Give the learner a short explanation and ask them to write the takeaway, its
supporting evidence and its limit. Then ask a second listener to restate the
takeaway and identify what remains uncertain. Test one version with an explicit
marker and one with a visual or written recap.

This tests takeaway recovery, compression accuracy, qualification retention and
format choice. It does not establish that summary markers improve trust,
memory or action.
