The first relation is more precise than “the speech repeats itself.” A recalled
teaching object supplies a concrete early image. The close explicitly invokes
that object again, now to contrast past teaching with present self-understanding.
The later reference changes its role rather than simply duplicating the earlier
description. This is a textual mechanism hypothesis; no listener memory or
persuasion benefit has been measured.

## The surrounding structure matters

The retained address moves from thanks and a narrated correction to community
acknowledgment, a question about reconciling experience and upbringing, a change
narrative, broader commitments, a dedication and a closing return. The central
narrative presents personal change as evidence that change is possible. That is
the speaker's argument, not independent proof of the narrated causal explanation.

Two boundaries prevent overreading. The opening says a friend supplied a
definition, but does not reproduce the definition itself. Later, a recalled
duration is approximate and one caption explicitly contains an inaudible
marker. These remain limitations, not repaired facts. An invitation to audience
participation does not establish an actual audible response or its effect.

## Comparing this address with the interview

The [interview follow-up](full-context-interview-01.md) contains prompts and
intervening marked turns before an explicit return to a particular encounter.
This address contains no marked interviewer questions in the retained text.
Its returns occur within a monologue-like address. That distinction supports
different units of analysis, not a ranking of the speakers or formats.

| Coding question | Address | Interview |
| --- | --- | --- |
| What returns? | Concrete image, phrase, metaphor | Individual encounter; separately, a decision basis |
| Who supplied the frame? | No interviewer prompt is marked in retained text | Several questions supply a frame before responses develop it |
| Does the return cross marked turns? | Not established in this transcript | Yes, for the individual-encounter example |
| What must not be merged with a return? | Another supporter under the same theme | Different personal-stakes examples under the same theme |
| What effect is demonstrated? | None measured | None measured |

This is a **purposive two-source contrast**, not a matched comparison, prevalence
estimate, independent validation or general claim about monologues and interviews.
Different occasions, subject matter, editing and audience remain confounds.
Textual self-disclosures and attributed experiences are not grounds for inferring
additional private traits or psychological states. Source historical/legal claims
are not independently verified by this communication analysis.

## A usable coding rule to test next

Record both spans and specify what returns: the same person/event, image,
phrase, metaphor, or prior explanation. Code broad thematic continuity with a
new example separately. Record prompts, marked intervening turns and any
change in the returning material's role. Have another reviewer apply these
definitions before estimating recurrence; test audience outcomes separately.

Practice exercise: outline an existing talk and connect an early image to its
later use. Explain what the later use adds. If the link is only that both parts
discuss the same broad topic, label it thematic continuity rather than an
explicit return. This is an analytical exercise, not a validated prescription.
