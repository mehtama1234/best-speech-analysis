# Master goal: turn 395 talks into a trustworthy communication-learning system

## The goal in one sentence

Study the full fixed corpus for repeatable communication choices—what speakers
say, how they structure it, and what vocal or visible delivery can actually be
observed—then turn the strongest bounded hypotheses into adaptable lessons that
are independently reviewed and tested for teachability and listener
comprehension before they are called best practice.

This is a system for learning communication jobs, not a celebrity-imitation
library. The learner borrows a choice that may serve a situation; they do not
borrow a speaker's identity, accent, status, personality, body language,
trauma, biography or certainty.

## What the system must preserve

Every claim stays on its own evidence level:

1. **Transcript observation:** what retained captions say, with timestamps and
   neighboring context.
2. **Function hypothesis:** what the words may be doing, with alternate and
   indeterminate interpretations preserved.
3. **Recurrence candidate:** whether a form appears across distinct reviewed
   events after identity and duplication checks.
4. **Delivery observation:** what available audio/video shows or measures,
   including missingness, editing and accessibility limits.
5. **Mechanism hypothesis:** why a choice might reduce a listener problem; this
   is an explanation to test, not a result.
6. **Teachability evidence:** whether learners can recognize, explain, transfer,
   bound and revise the choice.
7. **Listener evidence:** whether listeners comprehend or recall matched,
   independently reviewed stimuli.

Frequency, polish, fame, generated files and passing tests cannot silently
promote one level into the next.

## Corpus and deliverables

The finished system must contain:

- full-context readings of all 395 fixed-corpus videos;
- exact retained wording, timestamps, source identity and recognition-error
  boundaries;
- a searchable evidence bank and phrase-form inventory;
- independently reviewable identity, function, phrase, recurrence, delivery
  and counterexample workbooks;
- a bounded delivery layer that separates raw A/V, derived proxies, internal
  observations and independent observations;
- 18 communication-job lesson cards and a cross-talk synthesis;
- a learner-facing field guide and local practice surface;
- consented learner teachability records;
- independently reviewed and explicitly adjudicated matched listener stimuli;
- blinded listener comprehension/recall records;
- promotion audits, disagreement records, safety decisions and reproducibility
  manifests.

## The 18 communication jobs

These are practical problems, not personality types:

| Job | Adaptable form |
|---|---|
| Opening | Name the room or question; state why it matters; preview the route. |
| Closing | Return to the point; name the limit or next step; release the turn. |
| Question | Ask one specific question; give context; allow an answer or opt-out. |
| Answer or response | Answer the literal point; add a useful frame; give the bounded answer. |
| Story or personal experience | Give a bounded scene; say what it illustrates; state what it cannot prove. |
| Example or case | State the claim; give one case; return to the claim and evidence boundary. |
| Contrast or disagreement | Name the earlier view; identify the change; state the present view and overlap. |
| Correction or reframe | Acknowledge the starting frame; explain the correction; answer the better question. |
| Repair or self-correction | Mark the error; replace it plainly; continue without over-explaining. |
| Qualification or boundary | State the claim; name its condition or evidence status; say what would change it. |
| Definition or explanation | Name the term; give its plain meaning; show one example and one boundary. |
| Transition or structure | Close the current point; name the relationship; enter the next point. |
| Callback or repetition | Introduce an anchor; return with a changed application; avoid empty repetition. |
| Humor or rapport | Use safe lightness about yourself or the setting; return clearly to the point. |
| Credit or acknowledgment | Name contribution; connect it to the result; state what remains owed or unfinished. |
| Call to action or audience role | Name the problem; offer a bounded action and owner; state consent and limits. |
| Persuasion or advocacy | State the stake; show the mechanism; name tradeoffs and accountable actors. |
| Reflection or value frame | Describe the event; name the value; separate interpretation from verified fact. |

The [learner field guide](learner-field-guide.md) contains the card-level
examples, phrase families, practice prompts and non-fit warnings.

## The recurring cross-talk moves

Across jobs, the provisional synthesis groups the corpus into eight reusable
operations:

1. **Orient before detail:** context → stake → route; later point → limit or
   next step → release.
2. **Make an idea inspectable:** claim → concrete instance → interpretation →
   boundary.
3. **Answer, then frame:** direct answer → useful frame → condition or limit.
4. **Make change visible without manufacturing an enemy:** earlier frame →
   reason for change → present frame → overlap.
5. **Repair in public:** “I said X” → why X is incomplete or wrong → accurate Z.
6. **Convert credit into agency and responsibility:** contribution/problem →
   accountable actor → bounded action → support, consent and limit.
7. **Return to an anchor with changed use:** anchor → development → return with
   new application.
8. **Make the next turn answerable:** specific invitation → context → answer or
   decline path → next turn.

These are hypotheses for practice. The same phrase can perform different jobs;
no phrase is a magic word.

## How words become a lesson

For every candidate pattern, the lesson should show:

- the listener problem and smallest useful outcome;
- exact source wording with surrounding context and timestamp;
- the speaker-independent structure in plain language;
- adaptable phrase forms, not scripts to copy;
- why the move might help and what would falsify that explanation;
- an example, an alternate-function case and a non-fit case;
- evidence, uncertainty, consent, power and accessibility boundaries;
- a rehearsal task, listener-restatement check and revision step.

Use exact phrase forms as retrieval handles—such as “for example,” “in other
words,” “the point is,” “what matters,” “rather than,” “I think,” “it depends,”
“we need to,” and “let’s”—then rewrite the meaning for the learner's actual
relationship and situation. Never teach the source phrase without its job,
conditions and limits.

## What to inspect in delivery

When raw media exists, inspect rather than imitate:

- pause placement, pacing, turn timing and interruption/yielding;
- emphasis, pitch movement, loudness and vocal effort;
- gaze, posture, gesture, facial movement and physical orientation;
- speaker visibility, microphone, room, captions, music and camera edits;
- whether a visible or vocal feature is continuous, isolated, aligned to the
  retained words and accessible in another modality.

RMS, pitch, speech activity, spectral values and frame detectors are navigation
proxies. A midpoint frame cannot prove emotion, confidence, intention, gesture
meaning, audience response or effectiveness. The fixed corpus currently has
395 transcript reviews, while local media availability is separate: 31 raw
A/V items, 6 derived-feature-only items and 358 transcript-only items. The
36-sample delivery queue is an inspection route, not a validated nonverbal
library.

## The learner practice loop

1. Choose the communication job, not a person to imitate.
2. State the listener problem and smallest useful outcome.
3. Read one full-context example and mark the words doing the work.
4. Rewrite the structure in your own language and relationship.
5. Add the relevant condition, evidence, consent or limit.
6. Choose an accessible delivery mode: typed, spoken, captioned or
   asynchronous.
7. Ask a listener to restate the point and name what remains unclear.
8. Record the non-fit case, safety issue or unintended burden.
9. Revise the wording, function or delivery choice and try again.

One practice response is a learning log, not proof of general effectiveness.

## End-to-end validation sequence

The first promotion target is a five-job vertical slice. The gates are:

1. independently verify speaker, event, upload correspondence and duplication;
2. independently review function labels in full context;
3. independently review exact phrase forms and recurrence candidates;
4. complete manual delivery observations and independent multimodal review;
5. complete absence, failure, alternate-function, confound and misuse checks;
6. independently review and adjudicate the lesson packet;
7. run the consented learner teachability protocol;
8. independently review listener pair equivalence, accessibility, safety and
   blinding;
9. adjudicate the reviews and emit a lock artifact only if every pair passes;
10. run the blinded listener comprehension/recall protocol;
11. audit missingness, disagreements, safety and claim boundaries;
12. promote only the bounded claim actually supported by the chain.

The listener gate is deliberately separate from learner satisfaction and from
claims about the original famous speaker's effectiveness.

## Definition of done

The project is done only when the acceptance matrix has no open requirement;
every promoted job has the complete evidence chain; every export passes its
validator; disagreements have adjudication records; audiovisual absence is
visible; and the dashboard distinguishes transcript coverage, audiovisual
coverage, internal observations, independent observations, practice logs,
learner evidence, listener comprehension and effectiveness claims.

Generated workbooks, smoke tests and manifests are infrastructure. They do not
count as independent reviews, learner records or listener outcomes.

## Current honest state

The transcript/context layer is complete for all 395 fixed-corpus videos, and
the 18-job lesson, practice, learner, listener and review infrastructure is
operational. The repository has no real independent review exports, no
consented learner records, no locked listener pairs and no listener outcome
records. Therefore the lessons are useful provisional learning hypotheses, not
validated universal best practices.
