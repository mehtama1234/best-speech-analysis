# Vertical slice 02 learner-check draft

Status: candidate task bank; not piloted.

The [task bank](../research/vertical-slice-02-learner-task-bank.json) has four
tasks for each candidate: recognition, transfer, non-fit/boundary and a matched
control. It deliberately tests the communication job and its limits, not the
ability to imitate a celebrity.

Score each response for job recognition, plain-language explanation, bounded
transfer, non-fit recognition, safety/accessibility and listener restatement.
Do not promote a candidate if a learner can reproduce the surface form but
cannot state when it should not be used.

The bank is separate from the fixed five-pattern learner instrument. It must be
reviewed for stimulus quality and run with consented participants only after the
three candidate packets have passed their evidence gates.
