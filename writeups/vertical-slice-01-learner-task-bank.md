# Vertical slice 01 learner task bank

Status: **draft; not piloted**.

This bank fixes the stimuli for a future learner run: 20 tasks across five
patterns, including new-example recognition, transfer, misuse/non-fit and a
matched plain-communication control for each pattern. The prompts use original
ordinary scenarios rather than requiring learners to disclose personal or
sensitive experiences.

The answer keys and expected features are facilitator-facing. Randomize order
within phase, preserve each learner's assignment and lesson version, and record
uncertainty or disagreement rather than forcing a binary score.
