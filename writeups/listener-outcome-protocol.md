# Listener-outcome protocol

Status: **design complete, not run**.

A result can show differences in the measured listener task under this protocol. It cannot establish that a celebrity's delivery caused trust, long-term memory, persuasion, engagement or action in general.

## Design

- Comparison: randomized matched control versus pattern-informed version.
- Unit: listener-session-by-stimulus.
- Analysis: blind rubric scores for comprehension and recall, with condition and stimulus uncertainty.

## Listener tasks

| Task | Measure |
|---|---|
| `main_point_recall` | blind rubric score 0–2 |
| `evidence_or_example_identification` | blind rubric score 0–2 |
| `limit_or_uncertainty_identification` | blind rubric score 0–2 |
| `requested_action_identification` | blind rubric score 0–2 |
| `confusion_and_load` | coded response plus optional rating |
| `delayed_recall` | blind rubric score 0–2; only if delay and consent are feasible |

## Safety and accessibility

- Use plain-language consent and allow withdrawal without penalty.
- Offer text, captioned audio/video and screen-reader-compatible response modes.
- Do not require trauma, medical, political or personal disclosures.
- Minimize retention of recordings; obtain separate permission for any recording.

## Not yet evidence

The repository contains no consented listener observations or locked matched stimulus set yet.
